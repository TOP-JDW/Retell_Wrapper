Use British English in the interface and documentation. Use the dedicated Supabase development project. Keep membership checks on the server and enforce access through PostgreSQL row-level security. The Supabase secret key is read only in lib/admin.ts and used only by owner-checked member actions; never expose it to the browser, commit it or put it in a NEXT_PUBLIC_ variable. Retell is read-only: the app may only list agents and calls, and read one call, through lib/retell.ts, using a restricted key that is read only in lib/retell-server.ts. Never add a request that creates, updates or deletes anything in Retell, places a call, or sets up a webhook, and never store phone numbers, transcripts or recordings without an explicit decision. Recordings and transcripts are shown only to owners and admins, fetched live, and recordings are relayed through the app so Retell's links never reach the browser. When client logins exist, a client's own users may also see them, but only for that client's agents and only when an owner or admin has turned on that client's recordings setting (clients.recordings_for_client, off by default). Run npm test, npm run build and npm run typecheck before submitting changes.
